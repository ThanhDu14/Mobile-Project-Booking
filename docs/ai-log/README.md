# Nhật ký sử dụng AI

Theo proposal mục 13, mỗi lần dùng AI hỗ trợ đều phải ghi log.

- **Tên file:** `YYYY-MM-DD_<thanh-vien>_<NN-nhom>_<mo-ta-ngan>.md`, ví dụ `2026-10-05_A_01-account_otp-flow.md`
- **Mẫu:** [`_template.md`](_template.md)
- **Nguyên tắc:** không đưa dữ liệu cá nhân thật hoặc khóa bí mật vào prompt, và phải giải thích được mọi đoạn mã đã nộp.
