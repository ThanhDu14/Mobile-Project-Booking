# Wireframe SmashNow

Toàn bộ màn hình được thiết kế trên canvas [SmashNow Screens](https://claude.ai/artifact/9v89i3NEiUfw7mACk3zgq3), dùng design system [SmashNow](https://claude.ai/artifact/6E4H2MNewaNvMPe18vwnB3). Canvas có prototype bấm được và bản sáng/tối của từng màn.

| File | Nội dung |
|---|---|
| [`smashnow-wireframes-2026-10-13.zip`](smashnow-wireframes-2026-10-13.zip) | 80 ảnh PNG (xuất ngày 13/10/2026, khớp spec sau commit `0c56d5c`), chia thư mục theo spec |

Ảnh lẻ của từng tính năng nằm trong `specs/NNN-<ten>/ui/`, đặt tên `NN_<nhom>_buocX_mo-ta.png` theo [team contract](../../team-contract.md#4-kế-hoạch-10-tuần). Mỗi thư mục `ui/` có `README.md` liệt kê ảnh và artboard tương ứng.

Khi sửa design trên canvas, xuất lại ảnh, thay các file trong `specs/*/ui/` và tạo zip mới mang ngày xuất.
