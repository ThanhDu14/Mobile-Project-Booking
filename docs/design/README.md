# Thiết kế

| Thư mục | Nội dung |
|---|---|
| [`architecture/`](architecture/) | Kiến trúc tổng thể (layer, module theo feature), sơ đồ điều hướng theo vai trò |
| [`database/`](database/) | Sơ đồ ER, collection Firestore, Firebase Security Rules, chiến lược chống trùng lịch (transaction) |
| [`wireframes/`](wireframes/) | Wireframe và link Figma, đặt tên theo mã nhóm `NN_...` |

Thiết kế chỉ dùng cho một tính năng thì đặt trong `specs/NNN-.../` (`data-model.md`, `contracts/`). Thư mục này chỉ chứa thiết kế dùng chung cho nhiều tính năng.
